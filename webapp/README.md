# Portfolio Web App

React, TypeScript и Vite-приложение портфолио.

## Быстрый запуск

```sh
npm install
npm run dev
```

## Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Запустить локальную разработку |
| `npm run build` | Проверить типы и собрать приложение |
| `npm run typecheck` | Проверить TypeScript |
| `npm run lint` | Проверить код ESLint |
| `npm run format` | Форматировать Prettier |
| `npm run format:check` | Проверить форматирование |

## Структура

- `src/app` — маршрутизация приложения.
- `src/components` — переиспользуемые компоненты интерфейса.
- `src/pages` — страницы маршрутов.
- `src/types` — общие типы данных.
- `src/styles` — глобальные стили и дизайн-токены.

## Соглашения

- TypeScript работает в строгом режиме; типы экспортируются из `src/types`.
- Компоненты и типы именуются `PascalCase`, переменные и функции — `camelCase`, CSS-классы — `kebab-case`.
- Компоненты отвечают за представление, конфигурация данных хранится отдельно, общие элементы размещаются в `components`.
- В исходном коде не оставляются комментарии; смысл выражается названиями, типами и структурой.
- Перед коммитом запускаются `npm run typecheck`, `npm run lint` и `npm run format:check`.
- Коммиты оформляются по Conventional Commits: `feat:`, `fix:`, `docs:`, `refactor:`, `style:`, `chore:`. Пример: `feat: add portfolio homepage`.
- Один коммит содержит одно логически завершённое изменение; сообщения пишутся в повелительной форме на английском языке.
